# Matrix Command Coverage Registry

This registry tracks the Matrix v2 command families this MCP server exposes through typed `vbmatrix_*` tools. It is directly maintained from `src/core/commands.ts`, `src/tools/*`, and `docs/research.md`; it is not a full VB-Audio product inventory.

Status values:

- `Implemented`: typed tool coverage exists.
- `Partial`: some documented commands are covered, with explicit gaps.
- `Deferred`: intentionally out of current scope until safety or product behavior is designed.
- `Partial + destructive sub-actions`: some typed coverage exists, and at least one sub-operation is destructive or gated.
- `Unsafe/destructive/file-affecting`: covered only behind confirmation and safety gates, or intentionally deferred.
- `Unknown`: no source-linked command surface is available in this repo.

Registry dimensions:

- Tool coverage is tracked in the `Tool` and `Status` columns.
- Read/write semantics are tracked by the command family syntax: `...?;` rows are read-only, assignment/action rows are writes, and local snapshot/diff rows do not send Matrix commands.
- SUID or target requirements are tracked in each command family. `Point`, `Slot`, `Input`, `Output`, and `Zone` rows require explicit typed targets; `Command.*` status rows have no SUID target.
- Validation evidence is tracked by `Source` and `Notes`: live-observed behavior is called out where available, typed builders/tests are linked through source paths, and docs-only/deferred behavior is explicitly marked.

## Command Family Coverage

| Command family                                                                   | Coverage                          | Reason / typed gap                                                                                                                                   |
| -------------------------------------------------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Command.Version`, `Command.Engine`, `Command.Master` queries                    | Implemented                       | Covered by status tools and snapshot metadata.                                                                                                       |
| `Command.Restart`                                                                | Unsafe/destructive/file-affecting | Covered only as fixed `vbmatrix_restart_engine`; broad command execution is not exposed.                                                             |
| Raw/free-form VBAN-TEXT command execution                                        | Deferred                          | Explicitly out of scope to avoid bypassing typed validation and safety gates.                                                                        |
| `Point(...)` single-point gain/mute/phase/query/remove                           | Implemented                       | Covered by primitive point tools with query-before-write.                                                                                            |
| `Point(...)` range gain/mute/phase/remove                                        | Partial                           | Covered by dry-run-first `vbmatrix_apply_point_range`; aggregate range state queries remain unverified.                                              |
| `Zone(...)` gain/mute/phase/reset/copy/store/add                                 | Partial + destructive sub-actions | Covered by dry-run-first `vbmatrix_apply_zone`; reset/removal sub-actions are destructive-gated and aggregate zone state queries are not documented. |
| `Input(...)` / `Output(...)` label query                                         | Implemented                       | Single-channel and documented range query syntax are covered.                                                                                        |
| `Input(...)` / `Output(...)` non-empty label set                                 | Partial                           | Single-channel set is covered; non-empty range label assignment is deferred because the source docs only show range query/removal.                   |
| `Input(...)` / `Output(...)` empty label removal                                 | Implemented                       | Single-channel and documented range removal are covered.                                                                                             |
| `Input(...)` / `Output(...)` route reset                                         | Unsafe/destructive/file-affecting | Covered with confirmation and destructive gate.                                                                                                      |
| `Slot(...)` info/online/running status/master/device queries                     | Implemented                       | Covered by `vbmatrix_get_slot_info`.                                                                                                                 |
| `Slot(...)` online/master writes                                                 | Implemented                       | Covered with write gate and query-before-write.                                                                                                      |
| `Slot(...)` reset/device assignment/device removal                               | Unsafe/destructive/file-affecting | Covered with confirmation and destructive gate because these can disrupt live audio.                                                                 |
| `PresetPatch[n]` status queries                                                  | Implemented                       | Covered by `vbmatrix_get_preset_patch`.                                                                                                              |
| `PresetPatch[n]` scene operations and metadata edits                             | Partial + destructive sub-actions | Documented apply/recall/copy/paste/delete/gain/mute/phase/resetZone/update/name/comment are covered; scene mutations are destructive-gated.          |
| Preset patch load/save/save-as and preset grid file operations                   | Deferred                          | File-affecting behavior needs path safety design before typed tools are added.                                                                       |
| Full-matrix scan / dump commands                                                 | Deferred                          | Current tools require explicit targets to keep scans bounded and opt-in.                                                                             |
| VBAN service, stream, and Matrix application configuration writes                | Unknown                           | No source-linked Matrix command surface is documented in this repo; use the Matrix UI with an operator in the loop.                                  |
| Meter streaming / VBAN SERVICE subscriptions                                     | Deferred                          | Out of MVP; not represented by the current VBAN-TEXT command builders.                                                                               |
| Broad `Remove`, `Reset`, `ResetGrid`, `Shutdown`, or similar system-wide actions | Deferred                          | Not exposed without a named source-linked command, typed scope, and safety design.                                                                   |

## Maintenance Notes

- Update this file whenever a `vbmatrix_*` tool is added, removed, renamed, or changes the command family it covers.
- Link new rows to the command builder in `src/core/commands.ts` and the tool registration in `src/tools/`.
- Keep fuzzy audio intent out of this registry. Deterministic code should expose explicit facts and validation; agents decide intent.
